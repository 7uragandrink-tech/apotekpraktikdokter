Lupa Password
Dokter / staf: minta Pemilik mereset password Anda (Pengaturan → Pengguna → ikon kunci), lalu Anda diminta membuat password baru saat masuk.
Pemilik: isi Kode Pemulihan terbaru (12 karakter, tanda “-” otomatis); username boleh dikosongkan. Kode bisa dilihat kapan saja di Pengaturan → Keamanan Akun. Setelah dipakai, kode baru dibuat otomatis.
← Kembali ke halaman masuk
Kode hilang? Pemilik skrip dapat menjalankan fungsi resetPasswordPemilik di editor Apps Script.
Password Diatur Ulang
Kode lama sudah terpakai. Simpan kode pemulihan baru ini (catat, foto, atau unduh) untuk berjaga-jaga di lain waktu.
